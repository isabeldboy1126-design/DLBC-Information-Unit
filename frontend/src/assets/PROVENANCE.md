# Locally bundled official assets
Retrieved 30 September 2026. No package installation. Files are unmodified upstream assets; Icon.jsx embeds only their static path data.

Three upright WOFF2 faces are the minimal face subset used: Source Sans 3 Regular/Semibold and Source Serif 4 Regular. No remote font or icon service is used. Full character coverage is retained. Fallbacks are system UI and Georgia.
