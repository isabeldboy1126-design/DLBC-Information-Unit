# Source and licence notes

Default machine-readable corpus used by the builder:

- npm package `kjv@1.0.0`, `json/verses-1769.json`
- jsDelivr delivery URL: `https://cdn.jsdelivr.net/npm/kjv@1.0.0/json/verses-1769.json`
- The package describes the KJV corpus as public domain.

Independent reference/source research:

- Project Gutenberg hosts the King James Bible and marks it public domain in the United States.
- Midvash `bible-data` ships a 66-book 1769 KJV as JSON and SQLite and identifies it as public domain.

Important jurisdiction note:

The Authorized/King James Version has special Crown rights treatment in the United Kingdom. Review distribution requirements if this product is deployed or distributed there. The DLBC app can avoid repeatedly redistributing the corpus by installing/indexing it once in the deployment environment.
